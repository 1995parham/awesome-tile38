# Awesome Tile38 [![Awesome](https://awesome.re/badge-flat2.svg)](https://awesome.re)

> A curated list of awesome [Tile38](https://tile38.com/) software and resources.

[Tile38](https://tile38.com/) is an open source, in-memory geolocation data
store, spatial index, and real-time geofencing server.

## Contents

- [Official](#official)
- [Clients](#clients)
  - [Go](#go)
  - [Python](#python)
  - [Node.js](#nodejs)

## Official

- [Tile38](https://github.com/tidwall/tile38) - The Tile38 server itself: real-time geospatial and geofencing.
- [Client Libraries](https://tile38.com/topics/client-libraries) - Official list of client libraries maintained by the Tile38 project.

## Clients

### Go

- [t38c](https://github.com/cjkreklow/t38c) - Tile38 client library for Go.

### Python

- [pyle38](https://github.com/iwpnd/pyle38) - Async, fully typed Python client for Tile38.

### Node.js

- [tile38-client](https://github.com/tobilg/tile38-client) - Node.js client with a fluent query interface and live geofencing.
- [tile38](https://www.npmjs.com/package/tile38) - Tile38 client for Node.js published on npm.

## Miscellaneous

- [tile38-ha](https://github.com/RashadAnsari/tile38-ha) - Docker image for making Tile38 HA with Redis Sentinel.
- [tiles](https://github.com/1995parham/tiles) - Tile38 shard utility, the controller and query router for sharded clusters.
- [tile38-viewer](https://github.com/leighghunt/tile38-viewer) - Tool to visualise the state of events in Tile38.
