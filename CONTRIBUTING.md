# Contribution Guidelines

Thanks for your interest in making **Awesome Tile38** better! Please take a
moment to review these guidelines before opening a pull request.

## Adding to the list

- Make an individual pull request for each suggestion.
- Add your entry to the most fitting section. If none fits, propose a new one.
- Keep the list alphabetically ordered within each section where practical.
- Use the following format: `[name](link) - Description.`
- Keep descriptions short, clear, and free of marketing language.
- End every description with a period.
- Link to the project's canonical repository or homepage, not a mirror or fork.
- New categories or improvements to existing ones are welcome.
- Check your spelling and grammar.

## Quality standards

To stay on the list, an entry should be:

- Actively maintained, or clearly still useful.
- Relevant to [Tile38](https://tile38.com/) users.
- Documented well enough for others to get started.

## Verifying your changes

The list is checked with [awesome-lint](https://github.com/sindresorhus/awesome-lint).
Run it locally before submitting:

```sh
npx awesome-lint
```

## Reporting problems

Found a broken link or an outdated entry? Open an issue or send a pull
request removing/updating it — both are appreciated.
